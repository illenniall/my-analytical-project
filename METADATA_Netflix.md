# METADATA_Netflix.md — спецификация датасета и конвейера данных

## 1. Паспорт датасета

- **Источник:** Netflix Movies and TV Shows (Kaggle).
- **Исходный файл:** `netflix_titles.csv` — 8 807 строк, 12 столбцов.
- **Очищенный файл:** `netflix_titles_clean.csv` — 8 797 строк.
- **Единица наблюдения:** тайтл (фильм или сериал); бизнес-ключ `show_id` (уникален).
- **Период покрытия:** добавления в каталог с 01.01.2008 по 25.09.2021; 2021 год неполный.
- **Назначение:** EDA, SQL-валидация (DuckDB), статистические тесты, ML-эксперимент, витрины Power BI по схеме «звезда» с bridge-таблицами.

## 3. Профиль качества данных

**Пропуски:** director — 2 634 (29,91 %); country — 831 (9,44 %); cast — 825 (9,37 %); date_added — 10 (0,11 %); rating — 4 (0,05 %); duration — 3 (0,03 %).

**Проектные риски и принятые решения:**
1. `date_added` и `duration` загружаются как object — без парсинга временной анализ (`.dt`, `resample`) невозможен; в конвейер заложен парсинг дат и извлечение числовых минут.
2. Строки `date_added` могут содержать ведущие пробелы — перед парсингом выполняется очистка пробелов; строки без валидного года (10 шт.) исключаются из анализа динамики.
3. `country` и `listed_in` — списки: агрегации без разделения дают «склеенные сущности», поэтому справочники и bridge-таблицы строятся по раздельным значениям.
4. `duration` неоднородна: числовая длительность в минутах осмысленна только для фильмов; для сериалов длительность ведётся в сезонах. Фильмы с неизвестной длительностью заполняются медианой по фильмам (98 мин).
5. `rating` содержит редкие категории и пропуски — справочник использует объединённые категории (карта объединения в разделе 6).
6. 2021 год неполный — исключён из сравнений интенсивности пополнения и помечен как ограничение во всех выводах.

## 4. Спецификация ETL (порядок операций)

1. Заполнение пропусков `director`, `cast`, `country`, `rating` значением 'Unknown'.
2. Очистка ведущих пробелов в `date_added`.
3. Извлечение `year_added` регулярным выражением `(\d{4})`; исключение строк без валидного года (10 шт.).
4. Парсинг полной даты `pd.to_datetime(format='%B %d, %Y', errors='coerce')`.
5. Извлечение `duration_min` из «NNN min»; заполнение неизвестной длительности фильмов медианой по фильмам (98 мин).
6. Категоризация `movie_length_category`: «Сериал», «Длительность неизвестна», «Длинный (>120 мин)», «Стандартный (<=120 мин)».
7. Контроль качества: отсутствие пропусков в `show_id`, `type`, `title`, `date_added`, `release_year`; уникальность `show_id`; диапазон `release_year` 1900–2025.
8. Сохранение `netflix_titles_clean.csv` (utf-8-sig).

**Производные поля:** `year_added`, `duration_min`, `movie_length_category`, `month_added`, `month_name`, `content_key`, объединённая категория рейтинга.

**Методологическое уточнение:** `release_year` — год создания контента, `year_added` — год добавления в каталог; динамика пополнения библиотеки анализируется строго по `year_added`.

## 5. Статистические тесты и ML-эксперимент (воспроизводятся в notebook)

- **Тест 1 (биномиальный):** доля фильмов > 50 % — 69,7 %, 95 % ДИ [68,7 %; 70,7 %], p < 0,001.
- **Тест 2 (хи-квадрат):** тип контента × возрастная группа зависимы, p < 0,001.
- **Тест 3 (Манн–Уитни):** месячное пополнение 2019–2020 интенсивнее 2015–2018 (медианы 157 vs 75, p < 0,001; 2021 исключён как неполный).
- **ML (регрессия длительности фильмов, тест 20 %, random_state=42):** базовая медиана MAE 19,56 / R² −0,01; линейная 14,85 / 0,45; случайный лес 13,99 / 0,48; градиентный бустинг 13,66 / 0,50.

## 6. Витрины данных и модель Power BI

| Файл | Строк | Назначение |
|---|---|---|
| fact_content.csv | 8 797 | таблица фактов; `content_key` — суррогатный ключ |
| dim_country.csv | 122 | справочник стран (Unknown и пустые исключены) |
| bridge_country.csv | 10 003 | связь «многие-ко-многим» тайтл ↔ страна |
| dim_genre.csv | 42 | справочник жанров |
| bridge_genre.csv | 19 303 | связь «многие-ко-многим» тайтл ↔ жанр |
| dim_rating.csv | 11 | объединённые возрастные категории с расшифровками |
| dim_date.csv | 1 714 | календарный справочник |

**Связи:** dim → bridge и dim → fact — «один-ко-многим», односторонняя фильтрация; bridge → fact — двусторонняя кросс-фильтрация для корректной работы срезов по странам и жанрам.

**Карта объединения рейтингов:** TV-MA + NC-17 → «18+ (TV-MA)»; NR + UR + Unknown + TV-Y7-FV → «Без рейтинга»; остальные категории сохранены с пояснениями. Значения вида «NN min» в справочник не попадают.

## 7. Ограничения анализа

- Отсутствие просмотров, спроса, бюджетов и метрик качества: выводы ограничены структурой и составом каталога; причинные утверждения о стратегии платформы не формулируются.
- 2021 год покрыт до 25.09.2021 — его показатели несравнимы с полными годами.
- До 30 % значений `director`, `cast`, `country` — 'Unknown', что ограничивает глубину соответствующих срезов.
